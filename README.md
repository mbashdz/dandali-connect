# 🌍 Dandali Connect • African Social Network

**Dandali Connect** is a modern Afrocentric social platform built for Africa and the diaspora (with special optimization for the Hausa-speaking community across Nigeria, Niger, Ghana, and West Africa).

---

## 🚀 Key Modern Features

### 1. 🎨 Modern Afrocentric Brand & Design System
- **Authentic Brand Identity**: Custom geometric emblem inspired by the traditional *Dandali* (the central communal meeting circle) and Northern African motifs.
- **Color Palette**: Warm African Terracotta (`#E05A2B`), Saharan Gold Ochre (`#F59E0B`), and deep charcoal dark mode (`#120E0C`).
- **Glassmorphism & Micro-interactions**: Smooth frosted glass headers, rounded cards (`rounded-2xl`), and interactive feedback.

### 2. ⚡ Dandali Moments (Kowane Lokaci)
- **24-Hour Stories Carousel**: WhatsApp/Instagram/Facebook-style 24-hour photo and colored text status updates.
- **Interactive Story Viewer**: Fullscreen modal view with author information and mood color backdrops.

### 3. 🎙️ Oral Audio Posts & Voice Notes
- **Voice Storytelling**: Direct browser recording (`MediaRecorder` API) of voice notes into the feed.
- **Live Audio Waveform**: Built-in player with playback controls and dynamic audio frequency bars.

### 4. ❤️ Culturally Rich African Reactions
Facebook-style floating hover reaction bar with authentic expressions:
- **Ƙauna** ❤️ (*Love*)
- **Madalla** 👏 (*Bravo / Well done*)
- **Wuta** 🔥 (*Lit / Fire / Trending*)
- **Dariya** 😂 (*Haha / Joy*)
- **Alheri** 🤲 (*Blessing / Grace*)

### 5. 🛒 Dandali Kasuwa (Local African Marketplace)
- **Peer-to-Peer Local Trade**: Buy and sell traditional attire (*Babban Riga*, *Atamfa*, *Shadda*), mobile tech, crops/livestock, and handicrafts.
- **African Currencies**: Prices displayed in ₦ (NGN Naira), with support for ₵ (GHS), CFA, and KES.
- **Direct WhatsApp & Phone Integration**: Connect buyers straight to verified local merchants with 0 middleman fees.

### 6. 🌐 Dual-Language (Hausa & English) & Data-Saver Mode
- **Instant Language Toggle**: One-click switch in the top header between **Hausa** (*Dandalin Sada Zumuntar Afirka*) and **English**.
- **Data-Saver Switch**: Low-bandwidth mode that compresses image footprints for African mobile networks.

---

## 🛠️ Tech Stack
- **Framework**: Next.js 15 (Turbopack, App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS & Radix UI
- **Backend**: Firebase Authentication, Cloud Firestore, Cloud Storage
- **AI**: Genkit AI

---

## 💻 Running Locally

```bash
# Install dependencies
npm install

# Run TypeScript type check
npm run typecheck

# Start development server
npm run dev
# Visit http://localhost:9002
```
