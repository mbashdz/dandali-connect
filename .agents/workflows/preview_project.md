# Preview Project Workflow

This workflow details how to start the local development server and preview the **Dandali Connect** Next.js application.

## Step 1: Start Development Server
Start Next.js development server with Turbopack on port 9002:
```bash
npm run dev
```

## Step 2: Open Preview
Once the server starts, navigate to the local URL in your browser:
- Local preview: `http://localhost:9002`

## Step 3: Stop Development Server
To terminate the preview server when finished, press `Ctrl + C` in the running terminal.
