# **App Name**: Zaure Connect

## Core Features:

- News Feed: Display a feed of posts from followed users and pages, focusing on recent content.
- User Profiles: Display user profile information, including bio and posts, prioritizing visual clarity and ease of navigation.
- Follow System: Enable users to follow other users, in lieu of friending, without requiring mutual approval.
- AI-Enhanced Search: Create a simple and intuitive search functionality, allowing users to find content and people within the Zaure Connect ecosystem. If the search term is ambiguous, then use a tool powered by AI to suggest better search terms, or ask a clarifying question.
- Dark Mode Toggle: Enable both light and dark mode, selected using a simple toggle, respecting user preferences for accessibility.

## Style Guidelines:

- Primary color: Use warm earthy tones reflecting the Hausa culture.
- Secondary colors: Soft greens and blues for a calm and inviting feel.
- Accent: Bright orange (#FFA500) for call-to-action buttons and interactive elements.
- Clean and readable typography optimized for both English and Hausa scripts.
- Use culturally relevant icons inspired by Hausa art and symbolism.
- Prioritize a simple, intuitive layout with clear information hierarchy.
